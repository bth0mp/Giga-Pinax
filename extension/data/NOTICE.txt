Bundled Nomisma.org label data

nomisma-labels.json beside this file carries the English preferred label of
every Nomisma.org concept the bundled type records name in a field a card
shows: authority or issuer, denomination, mint, material and portrait. It
covers every corpus in this directory, so a local card reads a name here
instead of asking nomisma.org for one.

Source: https://nomisma.org/
SPARQL endpoint: https://nomisma.org/query
Retrieved 24 September 2026.

Nomisma concept data is available under Creative Commons Attribution 3.0:
https://creativecommons.org/licenses/by/3.0/

The labels are taken verbatim: nothing is reworded, and a concept Nomisma
publishes no English label for is absent here, so the card shows the bare
identifier rather than a name nobody published. The endpoint, the query text,
the retrieval date, the licence and the full fetched result are recorded in
scripts/data/nomisma-labels.json; the generated file is rebuilt from it with
`python scripts/import_rdf.py --write-labels`.

RIC ruler names come from extension/ric-people.js, not from this file: that
snapshot of Nomisma's own person concepts takes precedence over the labels
here for an OCRE authority or portrait. Both spell all 214 people the same.

The same file carries the modern names of the RIC VI-IX mint sections, and
those come from two sources. The Nomisma mint concepts are CC BY 3.0, as
above. Each of them links the same place in Wikidata with skos:closeMatch or
skos:exactMatch, and the labels and aliases of those Wikidata items are used
too: Wikidata dedicates its structured data to the public domain under the
Creative Commons CC0 1.0 Universal Public Domain Dedication,
https://creativecommons.org/publicdomain/zero/1.0/. Where such an item is the
Roman city rather than the town standing there now, one statement of it is
followed - the first of P1366, P276 and P131 it carries - and the names of
the town it leads to are used on the same terms, under the same CC0 1.0
dedication. Both sources were retrieved on 18 September 2026. The source
URLs, retrieval dates and licence statements are recorded in
scripts/data/nomisma-mints.json and scripts/data/wikidata-mints.json, and the
generated file's own header names both licences. The names are taken
verbatim; no mint was given a name neither source publishes.

Each corpus directory beside this file carries its own NOTICE.txt for the
American Numismatic Society type data it holds, which is under ODbL 1.0.
