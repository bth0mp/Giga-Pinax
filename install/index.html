DESKTOP · UNPACKED EXTENSION

Brave

Download once, extract the files, and load the folder into Brave.

Download Brave ZIP ↓
  1. Extract the downloaded ZIP into a folder you’ll keep.
  2. Open brave://extensions.
  3. Enable Developer mode, then select Load unpacked.
  4. Choose the extracted folder containing manifest.json.
  5. Pin Coin Lookup (Test Build) from the extensions menu.

Already working in the project? Load the dist/brave folder directly.

Updating an existing install: If you loaded the project's dist/brave folder, select Reload on Coin Lookup at brave://extensions after the new build is ready. For an extracted copy, replace the files in that same folder with this ZIP's contents, then select Reload. Reopen the popup.

DESKTOP · FIREFOX 142+

Firefox

A temporary install lets you test the popup before the build is signed.

Download Firefox ZIP ↓
  1. Open about:debugging.
  2. Select This Firefox.
  3. Select Load Temporary Add-on.
  4. Choose the downloaded ZIP, or manifest.json from its extracted folder.
  5. Open Coin Lookup (Test Build) from the extensions menu.

Removed when Firefox restarts. Permanent installation needs a Mozilla-signed build. This ZIP is unsigned.

Updating a temporary install: After updating the files in the folder you loaded, select Reload for Coin Lookup under This Firefox at about:debugging. For a ZIP installation, use Load Temporary Add-on to load this updated ZIP, then reopen the popup.
