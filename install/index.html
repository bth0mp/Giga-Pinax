GIGA PINAX · VERSION 0.3.0

Types and hammer prices, in your toolbar.

Version 0.3.0 looks up RIC and Price coin types from the American Numismatic Society's open OCRE and PELLA datasets and fetches the 100 most recent matching sales from acsearch with your own account. Install it in Brave or try it temporarily in Firefox.

DESKTOP · UNPACKED EXTENSION

Brave

Download once, extract the files, and load the folder into Brave.

Download Brave ZIP ↓
  1. Extract the downloaded ZIP into a folder you’ll keep.
  2. Open brave://extensions.
  3. Enable Developer mode, then select Load unpacked.
  4. Choose the extracted folder containing manifest.json.
  5. Pin Giga Pinax from the extensions menu.

Already working in the project? Load the dist/brave folder directly.

Updating an existing install: Rebuild, then select Reload on Giga Pinax at brave://extensions. For an extracted copy, replace its files with this ZIP's contents first. Reopen the popup.

DESKTOP · FIREFOX 142+

Firefox

A temporary install lets you test the popup before the build is signed.

Download Firefox ZIP ↓
  1. Open about:debugging.
  2. Select This Firefox.
  3. Select Load Temporary Add-on.
  4. Choose the downloaded ZIP, or manifest.json from its extracted folder.
  5. Open Giga Pinax from the extensions menu.

First use asks for access to numismatics.org, nomisma.org and www.acsearch.info. Allow each; if the popup closes, reopen it and select the button again.

Removed when Firefox restarts. Permanent installation needs a Mozilla-signed build. This ZIP is unsigned.

WHAT TO TRY

A reference and its type.

Try Price 23 or RIC I (2nd edition), Nero 306, then Get prices. Sign in on acsearch first if the popup asks you to.

Edit the acsearch search term to narrow the sales, and expand Inspect sales to open any of them on acsearch. Your choices stay in your browser.

Prices from acsearch with your own account · Contacts numismatics.org, nomisma.org and acsearch.info only · Local preferences
