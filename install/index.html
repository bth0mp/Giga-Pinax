GIGA PINAX · VERSION 0.20.0

Types and hammer prices, in your toolbar.

Version 0.20.0 looks up RIC, RRC, SC, Bopearachchi and Price coin types from the American Numismatic Society's open OCRE, CRRO, SCO, BIGR and PELLA datasets and fetches up to 100 recent matching sales from acsearch with your own account. Paste or right-click a whole lot description and it lists every catalogue reference in it. Sear Greek references such as SG6829v, and Krause world-coin references such as Netherlands KM# 123, get acsearch prices, and every card has a Search on CoinArchives link that only you open. Install it in Brave or try it temporarily in Firefox.

DESKTOP · UNPACKED EXTENSION

Brave

Download once, extract the files, and load the folder into Brave.

Download Brave ZIP ↓
  1. Extract the downloaded ZIP into a folder you’ll keep.
  2. Open brave://extensions.
  3. Enable Developer mode, then select Load unpacked.
  4. Choose the extracted folder containing manifest.json.
  5. Pin Giga Pinax from the extensions menu.

Already working in the project? Load the dist/brave folder directly.

Updating an existing install: Rebuild, then select Reload on Giga Pinax at brave://extensions. For an extracted copy, replace its files with this ZIP's contents first. Reopen the popup.

DESKTOP · FIREFOX 142+

Firefox

A temporary install lets you test the popup before the build is signed.

Download Firefox ZIP ↓
  1. Open about:debugging.
  2. Select This Firefox.
  3. Select Load Temporary Add-on.
  4. Choose the downloaded ZIP, or manifest.json from its extracted folder.
  5. Open Giga Pinax from the extensions menu.

Site access to numismatics.org, nomisma.org and www.acsearch.info is normally granted at install. If you turn it off later, Look up or Get prices asks again.

Removed when Firefox restarts. Permanent installation needs a Mozilla-signed build. This ZIP is unsigned.

WHAT TO TRY

A reference and its type.

Type RIC I² Nero 306, Crawford 44/5, SC 1266.2, Bop Euthydemus I 24A or Price 23 in the Reference box, where the cursor already waits, and select Look up: the popup shows the type with its median hammer price under the title and a line saying how far to trust it, such as Solid: 22 sales, 2024–2026; the obverse and reverse fold away under Obverse and reverse. In the empty box, the up arrow brings back your recent references. If it asks you to sign in on acsearch, sign in, then select Get prices. Type RIC 972 to list every type with that number, or type a ruler such as Titus in the RIC fields and the volume follows it. For a Bopearachchi type the acsearch search uses both spellings of the king and the citation as an exact phrase, such as (Hermaeus Hermaios) "Bopearachchi 20", and its matches are checked against numismatics.org in one request. Any other reference, such as BCD Boiotia 174b, gets acsearch prices without a type record; in the Reference box a ; list is listed reference by reference, and only the guided Other field searches it together; an RPC reference such as RPC I 1234 also gets an RPC online link that only you open. Type SG6829v for a Sear Greek variety: it reads as SG 6829 var., prices only, searched on acsearch as ("Sear 6829" "SG 6829"). Type Netherlands KM# 123 for a Krause Standard Catalog of World Coins number: world and modern coins, prices only, searched in acsearch's Modern coins category as Netherlands ("KM 123" "Krause/Mishler 123") — the same number is used in several countries, so the country you type in front makes the median far tighter, and its CoinArchives link opens that site's world section. Every card has a Search on CoinArchives ↗ button under the acsearch one (beside it in the right-click window), which opens CoinArchives' own search in a new tab; Giga Pinax fetches nothing from it.

Or select a reference on any web page, right-click and choose Look up “…” in Giga Pinax: it opens in a window you can drag to any size and looks the type and its prices up. Dealer spellings such as Craw. 44/5 and text copied from auction pages are read, and while that window is open each right-click looks up in it instead of opening another. The window button in the header opens the popup the same way.

Choose Last 5 years or Last 2 years above the median to see only recent sales, drawn from the sales already fetched; a line under the median says whether the last 2 years sold higher or lower than earlier sales, and Last sale links to the most recent one. Type a bid or an asking price in Check a price to see how many sales it tops and its multiple of the median, marked on the range bar. Edit the acsearch search term to narrow the sales, read the lowest and highest sale under the middle 50%, and expand Inspect sales to open any of them on acsearch. Your choices stay in your browser. Select the sun or moon in the header to switch between the light and dark look; until you do, the popup follows your system theme.
