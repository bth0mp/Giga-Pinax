Giga Pinax

Research ancient coins and what they sell for; keep your auction and collection records in your own browser.

Giga Pinax is a free, open-source extension for Brave, Chrome and Firefox. Type a catalogue reference or paste a whole lot description, and it finds the coin's type, gathers recent hammer prices, works out what a bid really costs, and keeps the coin in a local watchlist beside your own notes, photos and provenance. It has no account, no analytics and no server of its own, and it never places, changes or cancels a bid.

What it does

  • Research. RIC, Crawford, Price and Seleucid Coins references are answered from type data packaged with the extension, with no network request; Bopearachchi references and anything the package does not hold are looked up with the American Numismatic Society and Nomisma.org. An ambiguous reference offers choices instead of a guess.
  • Prices. A median of recent acsearch sales, fetched with your own signed-in acsearch session, and a separate median of CoinArchives public results. Each counts how many results cite your coin and keeps the rest out of the median, and currencies and providers are never mixed.
  • Bids. Hammer plus buyer's premium, shipping and payment fees, or the highest hammer a budget allows, with a fixed increment or a house's own increment ladder.
  • Records. Watchlist and auction queues, reminders, outcomes, provenance, measurements and photo links, and comparison of saved coins — all stored in your browser, with JSON backups you export yourself.

Install

Open the latest release and download the package for your browser under Assets — not GitHub's Source code archive. No GitHub account is needed.

Brave or Chrome

Extract the Brave ZIP into a folder you will keep. Open brave://extensions or chrome://extensions, turn on Developer mode, select Load unpacked, and choose the folder holding manifest.json. To update, extract the new ZIP over the same folder and select Reload.

Firefox 142 or later

When the release carries a signed package, giga-pinax-firefox-x.y.z.xpi, select it in Firefox and confirm the installation. It stays installed, and Firefox keeps it up to date by itself.

Otherwise, download the Firefox ZIP, open about:debugging, select This Firefox and Load Temporary Add-on, and choose the ZIP. Firefox removes a temporary add-on when it restarts.

The installation guide has every step and a first tour.

Privacy

Giga Pinax contacts a research provider only for a lookup or a price search you start, and your saved records never leave your browser unless you export them. The privacy policy lists every host it contacts and when.

This site has no scripts, cookies, web fonts or analytics. GitHub Pages serves it, and GitHub receives the ordinary request data of any visit.
