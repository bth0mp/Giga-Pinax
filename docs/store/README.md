# Store publication pack for 0.29.0

This directory contains prepared copy and reproducible artwork for Chrome Web Store and Firefox Add-ons. It does not record a submission, signature or publication. Both publisher dashboards were signed out when this pack was prepared.

- [LISTING.md](LISTING.md): shared and store-specific listing copy, permission explanations and privacy declarations.
- [REVIEWER-NOTES.md](REVIEWER-NOTES.md): functional review steps and build facts.
- [ASSET-CHECKLIST.md](ASSET-CHECKLIST.md): required images, dimensions and final screenshot slots.
- [assets](assets/README.md): packaged icon, reproducible 440×280 promotional artwork, and verified 1280×800 workspace screenshot. These satisfy the documented Chrome image minimum; further screenshots are optional.

Before submission, the publisher must provide the account identity and monitored contact fields required by each dashboard, choose any mandatory category or license field, and accept the store agreements and attestations personally. The repository has no `LICENSE` file; this pack grants no license and makes no legal attestation.

Until a private support address is supplied, listing support points to the public [bth0mp/Giga-Pinax issue tracker](https://github.com/bth0mp/Giga-Pinax/issues). Public issue forms must not be used for private auction or payment data.

Keep the Firefox Gecko ID `giga-pinax@local.invalid`. It is the existing stable unique ID; an email-shaped add-on ID is an identifier and need not be a deliverable mailbox.
